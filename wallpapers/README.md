# Wallpapers

Wallpapers used in my setup

Press `prefix + Shift+w` in tmux to choose a JPG, JPEG, PNG, or WebP image in a popup with fzf and a Kitty preview. Press Enter to apply it to every macOS desktop, or Escape to cancel. The popup stays open on errors so you can read them.

Inside tmux, reload the config with `prefix + r` first to enable image passthrough. macOS may ask you to allow your terminal to control System Events when applying a wallpaper for the first time.
