# dotfiles

My macOS dotfiles. Managed with [chezmoi](https://www.chezmoi.io/). Feel free to steal anything useful.

```sh
sh -c "$(curl -fsLS https://get.chezmoi.io)" -- init --apply smnatale
```

That command applies my whole setup, so have a look through the repo first.
